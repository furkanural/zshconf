# my-zsh-config

An opinionated zsh configuration — tuned completion system, staggered
(turbo) plugin loading via Zinit, Starship prompt — structured so you can
use it and keep pulling updates **without forking**: the repo is sourced,
never edited, and all personal/machine-specific configuration lives in a
local overlay outside the repo.

> Status: under construction. Full documentation (install, customization,
> architecture) lands before first release. The project name is provisional.
